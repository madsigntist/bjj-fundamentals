# BJJ Fundamentals Weekly Classes: Ready-to-Teach Plan (14 Weeks)

## Program Rules (Keep This Constant Every Week)

1. One class per week, 60 minutes.
2. One headline theme per class.
3. Two concepts maximum per class.
4. One memory phrase per class.
5. One cooperative drill, one game, one positional round.
6. Success is measured each class with one simple metric.

## Standard 60-Minute Class Flow

1. 0:00-0:05. Theme intro and one key question.
2. 0:05-0:12. Concept-linked warm-up.
3. 0:12-0:22. Teach core concept(s) and memory phrase.
4. 0:22-0:35. Cooperative drill.
5. 0:35-0:47. Constraint game.
6. 0:47-0:55. Positional rounds.
7. 0:55-1:00. Recap, win condition check, homework.

## Week 1

### Theme
Position first, then technique.

### Concepts
1. Positional hierarchy.
2. Universal decision framework (Six Questions).

### Memory Phrase
If I know where I am, I know what to do.

### Visual Aid
Positional hierarchy poster + Six Questions flowchart.

### 60-Minute Plan
1. 0:00-0:05. Explain tiers and why advancing one tier matters.
2. 0:05-0:12. Movement warm-up: hip switch, bridge, technical stand-up.
3. 0:12-0:22. Teach hierarchy and Six Questions in order.
4. 0:22-0:35. Drill 3: Positional Awareness Drill.
5. 0:35-0:47. Game: Coach calls random position. Student says tier and first priority before moving.
6. 0:47-0:55. Positional rounds: Start in side control bottom. Goal is verbalize first three priorities.
7. 0:55-1:00. Recap and assign homework.

### Win Condition
Student can correctly name tier and immediate priority in under 3 seconds.

### Weekly Metric
10 random position prompts. Track correct tier plus priority responses.

### Homework
Review hierarchy and say Six Questions out loud once daily.
