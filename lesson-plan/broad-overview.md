# Concept Fundamentals Class

## 1) Simple 60-minute class template (repeat every week)

1. Whiteboard: cover theme, concepts, and key cues.
2. Drill 1: cooperative drill for first concept.
3. Setup: discuss context and setup for second drill.
4. Drill 2: cooperative drill for second concept.
5. Feedback: open discussion to share insights on the positions.

This structure is easy for students to remember and gives you consistency.

## 2) How to chunk weekly content so it stays simple

Instead of one concept per week forever, teach in concept bundles.

Suggested 14-week cycle:

1. Week 1. Positional hierarchy + six-question decision loop.
2. Week 2. Base + posture.
3. Week 3. Frames + distance management.
4. Week 4. Movement fundamentals + elbow-knee connection.
5. Week 5. Inside position + hand fighting basics.
6. Week 6. Head control + hip control.
7. Week 7. Escape chain integration (survive to recover).
8. Week 8. Top control fundamentals (pin, weight, connection).
9. Week 9. Guard retention layers + inside leg position.
10. Week 10. Off-balancing + sweep vs submission choice.
11. Week 11. Passing gates (feet, knees, hips, upper body).
12. Week 12. Pressure passing vs movement passing.
13. Week 13. Submission phases (isolate, expose, break defense).
14. Week 14. Dilemma creation and chaining + pacing and energy management.

Then repeat the cycle with more resistance and better timing.

## 3) Concepts that should absolutely use visual aids

These will have the highest teaching payoff with posters and charts.

1. Positional hierarchy.
   What to include:

- Six tiers, worst to best.
- One primary objective per tier.
- Arrow rule: advance one tier at a time.

2. Universal decision framework.
   What to include:

- The six questions as a flowchart.
- Branches: if not safe, defend first.
- Small icons for safety, inside position, mobility, threats.

3. Escape sequence (Level 2).
   What to include:

- Six steps in order.
- Red warning: do not skip sequence.
- One common mistake under each step.

4. Passing gate sequence (Level 5).
   What to include:

- Gate 1 feet, gate 2 knees, gate 3 hips, gate 4 upper body.
- Visual checkpoint before advancing.
- Reset arrow if a gate is lost.

5. Submission phases (Level 6).
   What to include:

- 5-phase ladder.
- Rule: control before finish.
- Typical fail point at each phase.

6. Guard retention layers.
   What to include:

- Layer 1 to layer 4.
- If layer breaks, immediate next action.
- Recovery path back to attacking guard.

7. Dilemma template.
   What to include:

- Threat A and Threat B.
- If they defend A, B appears, and vice versa.
- Position and grips needed first.

## 4) Keep lessons engaging and memorable

1. Teach only one headline per class.
2. Use one phrase students repeat out loud.
3. Keep technical detail low, decision quality high.

Example memory phrases:

1. Position first, then technique.
2. Inside wins exchanges.
3. Head and hips steer everything.
4. Pass gates in order.
5. Control earns submissions.

## 5) A practical way to plan each week

For each class, write this on one page:

1. Theme.
2. Two concepts max.
3. One cooperative drill per concept.

Example metric ideas:

1. Escape success rate in 2-minute rounds.
2. Number of correct gate progressions.
3. Number of times students identify the correct next tier.
4. Number of clean sequence reps.
