## Standard 60-Minute Flow

1. 0:00-0:05 Theme intro and key question.
2. 0:05-0:12 Warm-up linked to concept.
3. 0:12-0:22 Teach core concept(s).
4. 0:22-0:35 Cooperative drill.
5. 0:35-0:47 Constraint game.
6. 0:47-0:55 Positional rounds.
7. 0:55-1:00 Recap and homework.
