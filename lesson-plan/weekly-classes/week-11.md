# Week 11: Pass In Order

## Class Goal

Students pass guard by solving gates in order, then stabilize control before advancing attacks.

## Concepts

1. Passing gate sequence.
2. Frame clearing urgency.

## Memory Phrase

Pass gates in order.

## Whiteboard Content

1. Decision rule under pressure: solve the current gate before attempting the next one.
2. Passing gate sequence: feet, knees, hips, then upper body control.
3. Frame clearing urgency: active frames must be cleared before scoring or attacking.
4. Sequence order: identify gate, clear block, stabilize, then progress.
5. Common fail point: passer reaches upper body while hip gate is still open.
6. Control target: maintain at least two control points while progressing gates.
7. Recovery rule: if partner rebuilds a previous gate, return and solve that gate again.
8. Transition from Week 10: Week 10 trained reaction-based choices, Week 11 applies the same read-and-choose discipline to passing gates.

## Suggested Teaching Wording

Opening: Most failed passes come from skipped gates.
Teaching point: Feet, knees, hips, upper body. Solve each gate before moving on.

### Opening Script (0:00-0:05)

Last week we trained reaction-based choices between sweeps and submissions. This week we apply that discipline to passing gates in order.

Today's focus is structured passing, not rushing to side control. If you skip a gate, you usually get reset.
Repeat with me: pass gates in order. In every rep today, identify the current gate before you move.

### Core Script (0:12-0:22)

First concept is the passing gate sequence. Feet gate means controlling distance and hooks. Knee gate means clearing knee shields and leg barriers. Hip gate means pinning rotation. Upper-body gate means clearing frames and settling chest control.

Second concept is frame clearing urgency. Even after you pass legs and hips, active upper-body frames can still undo the pass. Clear frames before you call the pass complete.

Watch this rep: I clear feet, then knees, then pin hips. Only then do I settle chest-to-chest and clear upper-body frames. I do not jump to the end.

Common mistake: passer clears legs and dives chest-first while hips remain mobile. Result: bottom player recovers guard. Correction: return to hip gate, pin rotation, then continue.

Partner cue for this block: call out "current gate" before each action.

## Drill

Drill 15: Gate-by-Gate Passing Chain (Level 2).

Setup:

1. Start in open guard passing scenario.
2. Passer identifies current gate out loud before each attempt.
3. Clear feet gate, then knees gate, then hips gate.
4. Settle upper-body control and clear frames before scoring pass.
5. Hold stabilized side control for a 3-count before reset.
6. If prior gate reappears, return to that gate and solve it again.

Coaching cues:

1. Freeze and check gate order if sequence breaks.
2. Reward clean gate progression before speed.
3. Require verbal callout each rep: "gate solved" before advancing.

## Positional Rounds (0:43-0:51)

1. Start in open guard passing scenarios.
2. Goal: complete all gates without skipping.
3. Round 1 constraint: pass only counts if all four gates are called and cleared.
4. Round 2 progression: no verbal calls, coach verifies gate order from movement.
5. 2 rounds x 4 minutes, switch roles each round.

## Suggested Recap Wording

Today we trained passing discipline through gate order, not speed.
When you solved gates in sequence, your passes stabilized and were harder to reverse.
In live rounds this week, score clean full-gate passes before submission attempts.

## Concept Transfer To Other Positions

1. Escapes also have ordered gates: safety, frame, move, recover.
2. Submissions also improve with ordered setup phases.
3. Transitions are cleaner when prerequisites are solved first.
4. Takedown finishing: clear base and hips before trying to settle upper-body control.

## Win Condition

Passer reaches stable side control by clearing all gates in sequence and holding control.

## Metric

Correct full-gate progressions versus total passing attempts.
Target: 2 to 3 clean full-gate passes per 4-minute round.

Secondary metric: percentage of passes where upper-body frames are cleared before score call.

## Practice This Week In Normal Class (Personal Live-Round Drill)

1. Personal drill: Gate Discipline.
2. During regular rounds, call gate order in your head while passing.
3. If a gate is not solved, do not skip ahead.
4. Track clean passes with full gate sequence.
5. Add one quality rule per round: hold a 3-count after pass before moving to attacks.

## Common Student Mistakes And Quick Corrections

1. Mistake: Passer jumps from feet to upper body.
   Quick correction: Return to missed gate and solve it first.
2. Mistake: Clears legs but ignores hip control.
   Quick correction: Pin hips before settling chest.
3. Mistake: Arrives in side control but frames remain active.
   Quick correction: Clear upper-body frames before score mindset.
4. Mistake: Student calls pass complete without stabilization hold.
   Quick correction: Require a 3-count control hold before scoring the pass.
